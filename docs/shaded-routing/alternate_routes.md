# Alternate Routes 시각화 도구

Alternate Routes를 지도에서 시각화하는 웹 기반 도구입니다.

## 기능

- 🗺️ **지도 기반 시각화**: Leaflet을 사용한 인터랙티브 지도
- 🛣️ **다중 경로 표시**: 최적 경로와 대체 경로를 다른 색상으로 표시
- 📊 **경로 비교**: 거리, 시간, 교차로 수 등 경로 정보 비교
- 🎨 **색상 구분**: 각 경로를 다른 색상으로 표시
- 🔄 **인터랙티브**: 경로 클릭으로 상세 정보 확인 및 지도 범위 조정

## 사용 방법

### 1. Valhalla 서비스 시작

```bash
valhalla_service valhalla.json 4
```

서비스는 기본적으로 `http://localhost:8002`에서 실행됩니다.

### 2. 브라우저에서 열기

```bash
# 파일 직접 열기
open alternate_routes_visualizer.html

# 또는 Python HTTP 서버 사용
python -m http.server 8080
# 브라우저에서 http://localhost:8080/alternate_routes_visualizer.html 접속
```

### 3. 경로 생성

1. **서버 주소**: Valhalla 서비스 주소 입력 (기본값: http://localhost:8002)
2. **출발지/목적지 좌표**: 위도와 경도 입력
3. **코스팅 방법**: 자동차, 자전거, 도보 등 선택
4. **대체 경로 개수**: 0-5 사이의 값 입력
5. **"경로 생성"** 버튼 클릭

### 4. 지도 사용

- **지도 클릭**: 출발지/목적지 설정
- **마커 드래그**: 출발지/목적지 위치 변경
- **경로 클릭**: 경로 정보 팝업 확인
- **경로 목록 클릭**: 해당 경로로 지도 이동 및 강조

## 경로 색상

- **빨강**: 최적 경로 (가장 빠른 경로)
- **파랑**: 대체 경로 1
- **초록**: 대체 경로 2
- **자홍**: 대체 경로 3
- **청록**: 대체 경로 4
- **노랑**: 대체 경로 5

## 기능 설명

### 경로 목록

좌측 사이드바의 "경로 목록" 섹션에서:
- 각 경로의 거리, 시간, 교차로 수 확인
- 경로 클릭 시 해당 경로로 지도 이동 및 강조
- 다른 경로는 반투명하게 표시

### 모든 경로 표시

"모든 경로 표시" 체크박스를 사용하여:
- 체크됨: 모든 경로를 동일한 투명도로 표시
- 체크 해제: 최적 경로만 강조, 대체 경로는 반투명

### 범례

좌측 사이드바 하단의 범례에서:
- 각 경로의 색상 확인
- 경로 이름 확인

## 문제 해결

### 경로가 표시되지 않음

1. Valhalla 서비스가 실행 중인지 확인
2. 서버 주소가 올바른지 확인
3. 좌표가 올바른지 확인 (위도: -90~90, 경도: -180~180)
4. 브라우저 콘솔에서 오류 메시지 확인

### CORS 오류

파일을 직접 열 때는 CORS 오류가 발생할 수 있습니다. Python HTTP 서버를 사용하세요:

```bash
python -m http.server 8080
```

### 경로를 찾을 수 없음

1. 해당 지역에 타일 데이터가 있는지 확인
2. 좌표가 타일 범위 내에 있는지 확인
3. 코스팅 방법이 적절한지 확인 (예: 도보는 자동차 전용 도로 사용 불가)
